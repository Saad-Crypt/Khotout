# صنعة الخط العربي — Android

Le fichier `index.html` du dépôt est intégré dans l'application Android via une WebView locale.

Pour construire l'APK : ouvrir **Actions**, choisir **Build صنعة الخط العربي APK**, cliquer sur **Run workflow**, puis télécharger l'artefact **sanaat-al-khatt-debug-apk** à la fin du travail.
